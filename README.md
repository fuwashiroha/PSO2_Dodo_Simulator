# PSO2 特殊能力追加シミュレーター
<img width="1811" height="1314" alt="image" src="https://github.com/user-attachments/assets/1d811448-1218-40c2-99b0-8c325d8b7368" />
『PHANTASY STAR ONLINE 2』旧PSO2向けの特殊能力追加シミュレーターです。

旧PSO2の特殊能力追加シミュレーターをベースに、オフライン化・中国語対応・機能追加・ルール修正を行ったものです。

本体と素材の特殊能力構成、継承率、合成率、拡張補正、追加アイテムなどをシミュレートできます。

## 主な機能

- 本体 + 素材1～5
- 1S～8S対応
- 特殊能力の継承・合成
- 特殊能力因子
- 各種レセプター
- カタリスト系
- ソール系
- グレア系
- レヴリー系
- ファクター系
- レッサー / EV系
- フレイズ系
- 特殊能力追加アイテム
- 能力追加成功率アイテム
- 報酬期間
- 同名装備補正
- スロット拡張補正
- 本体 / 素材間のドラッグ＆ドロップ
- Ctrl + ドラッグによる能力コピー
- 複数の「ゴミ」能力による穴埋め
- 全本体・素材を指定スロット数まで一括でゴミ埋め
- 全ゴミ能力の一括削除
- 保存 / 読込
- URLによる構成共有
- 日本語 / 中国語切り替え
- 選択中能力の基礎ステータス合計表示

## 基礎ステータス合計

右側の「追加候補 / 成功率」欄に、選択中の特殊能力による以下のステータス合計を表示します。

- 打撃力
- 射撃力
- 法撃力
- 技量
- 打撃防御
- 射撃防御
- 法撃防御
- HP
- PP

以下のような複合表記にも対応しています。

- `ALL+40`
- `S/R/T-ATK+30`
- `S/R/T-DEF+20`

## 基本操作

### 特殊能力を追加する

左側の「特殊能力一覧」から能力を選び、

- 本体
- 素材1
- 素材2
- 素材3
- 素材4
- 素材5

へ配置します。

配置済みの能力はドラッグ＆ドロップで移動できます。

`Ctrl` を押しながらドラッグすると、移動ではなくコピーになります。

### ゴミ能力

「ゴミ」は穴開け・スロット数調整用の100%継承能力です。

同じ装備内に複数配置できます。

画面下部から、

- 本体・全素材を1S～8Sまで一括でゴミ埋め
- 本体・全素材のゴミ能力を一括削除

ができます。

### 特殊能力因子

本体・素材に設定した一部能力は「因子」として指定できます。

因子を有効にすると、特殊能力因子のルールに従って追加候補へ表示されます。

### 追加アイテム

「追加アイテムを使用」を有効にすると、追加アイテム系能力が候補一覧へ表示されます。

追加アイテム能力の基礎成功率は100%です。

1回の特殊能力追加で使用できる追加アイテム能力は1種類のみです。

### 成功率補正

以下の補正に対応しています。

- 能力追加成功率アイテム
- 報酬期間
- 同名装備補正
- スロット拡張補正
- 錬成の導き等の特殊補正

旧PSO2のルールに基づいて最終成功率を計算します。

## 実装済み特殊ルール

### フレイズ系

対応能力：

- フレイズ・チェイス
- フレイズ・レスポンス
- フレイズ・ウィーク
- フレイズ・リカバリー
- フレイズ・リデュース
- フレイズ・ディケイ
- フレイズレセプター

フレイズ系能力は1つのみ付与可能です。

通常継承はできず、対応するフレイズレセプターがある場合に継承できます。

### レッサー / EV系

対応能力：

- レッサースタミナ I～V
- レッサースピリタ I～V
- レッサーパワー I～V
- レッサーシュート I～V
- レッサーテクニック I～V

EV系：

- EV・パワーHP
- EV・パワーPP
- EV・シュートHP
- EV・シュートPP
- EV・テクニックHP
- EV・テクニックPP

EV系は対応するレッサーV同士の組み合わせによる特殊合成に対応しています。

### 錬成の導き

本体に「錬成の導き」が付与済みの場合、その特殊能力追加時の成功率が +5% されます。

今回の追加候補として「錬成の導き」を選択しただけでは、その回の成功率には適用されません。

## 起動方法

本プロジェクトは完全な静的HTMLです。

ダウンロード後、

`index.html`

を直接開くだけで使用できます。

Node.js、Python、Webサーバー等は不要です。
