PSO2特殊能力模拟器使用说明
操作方法
打开：点击index.html打开追加模拟器
移动：可以对本体/素材列表下的能力进行拖动
复制：按住ctrl拖动能力时可以复制能力
辣鸡：填充用100%成功能力
保存：保存当前的内容（也可以自行复制保存浏览器上的链接，下次复制链接即可读取）
读取：读取上次保存的内容

『PSO2』特殊能力追加シミュレーター 使い方
操作方法
起動: index.html を開いてシミュレーターを起動します。
移動: 本体/素材リスト内の特殊能力をドラッグ＆ドロップで移動できます。
複製: Ctrl キーを押しながら特殊能力をドラッグすると複製できます。
ゴミ (素材埋め): 成功率100%の穴埋め用特殊能力です。
保存: 現在の状態を保存します。（ブラウザのURLをコピーして保存しておくことでも、次回そのURLから復元可能です）
読み込み: 前回保存した状態を読み込みます。
