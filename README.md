# PSO2 特殊能力追加シミュレーター

日本語 | [简体中文](README_CN.md)

旧PSO2向けの、オフラインで使える特殊能力追加シミュレーターです。

<img width="1910" height="1206" alt="image" src="https://github.com/user-attachments/assets/accd7ba7-fa43-41fa-bed6-7a87a978e212" />


## 主な機能

- 本体と素材5個の能力を編集。継承・合成・拡張・因子・追加アイテムに対応。
- 追加候補の成功率、全成功率、選択した能力のステータス合計を表示。
- 装備のドラッグ＆ドロップ、アイテムバッグ、特殊能力移植、合成レシピ。
- 複数プラン、保存データ、JSONの書き出し・読み込み、URL共有。
- コンパクト表示、日本語・中国語、システム連動／ライト／ダーク配色。

## 使い方

「Code → Download ZIP」でダウンロードして展開し、`index.html` をブラウザーで開いてください。インストールやサーバー起動は不要です。各ファイルと `icons` フォルダーを一緒に置いてください。

左側から能力を配置し、追加候補を選んで「追加シミュレート」を実行します。結果はバッグに追加されます。別の端末へ移すときは「書出」を使ってください。
