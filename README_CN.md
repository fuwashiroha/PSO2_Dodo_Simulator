# PSO2 特殊能力追加模拟器

[日本語](README.md) | 简体中文

面向 PSO2 旧国的离线特殊能力追加模拟器。

<img width="1908" height="1176" alt="image" src="https://github.com/user-attachments/assets/6e192c12-39c0-46f0-a4be-d20175a4e3bc" />


## 主要功能

- 编辑本体与五件素材，支持继承、合成、扩孔、因子和追加胶囊。
- 显示候选能力成功率、全部成功概率及所选能力的属性合计。
- 装备拖放、道具背包、特殊能力移植与合成配方。
- 多方案标签、方案保存、JSON 导入导出与链接分享。
- 紧凑排版、中日文切换、跟随系统／浅色／深色配色。

## 使用方法

点击「Code → Download ZIP」，解压后用浏览器打开 `index.html`，无需安装或启动服务。请保留同目录的其他文件和 `icons` 文件夹。

从左侧放入能力，勾选追加候选后点击「模拟追加」，结果会加入背包。跨设备转移数据时使用「导出」。
