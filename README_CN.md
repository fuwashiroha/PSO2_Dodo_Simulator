# PSO2 旧国 特殊能力追加模拟器
<img width="1891" height="1215" alt="image" src="https://github.com/user-attachments/assets/62a1ffac-1340-4386-bc3c-c2fec9fc83bb" />
这是一个用于《PHANTASY STAR ONLINE 2》旧国版本的特殊能力追加模拟器。

项目基于旧版 PSO2 特殊能力追加模拟器进行离线化、中文化和功能扩展，主要用于模拟本体与素材的特殊能力组合、继承率、合成率、扩槽补正以及追加道具等机制。

## 主要功能

- 支持本体 + 素材1～5
- 支持 1S～8S 特殊能力配置
- 支持特殊能力继承与合成
- 支持特殊能力因子
- 支持各种 Receptor / 保护类能力
- 支持 Catalyst、Soul、Glare、Reverie、Factor 等特殊合成
- 支持 Lesser / EV 系列
- 支持 Phrase 系列
- 支持特殊能力追加道具
- 支持能力追加成功率道具
- 支持奖励期间成功率加成
- 支持同名装备补正
- 支持扩槽成功率补正
- 支持本体 / 素材之间拖拽能力
- 支持按住 Ctrl 复制能力
- 支持多个“垃圾能力”作为开孔占位
- 支持一键将全部本体和素材补满至指定孔数
- 支持一键删除全部垃圾能力
- 支持保存 / 读取配置
- 支持通过 URL 分享配置
- 支持日文 / 中文界面切换
- 自动统计所选能力的基础属性合计

## 支持的基础属性统计

在右侧“追加候选 / 成功率”区域中，会自动统计当前所选能力的：

- 打击力
- 射击力
- 法击力
- 技量
- 打击防御
- 射击防御
- 法击防御
- HP
- PP

复合属性也会自动展开计算，例如：

- `ALL+40`
- `S/R/T-ATK+30`
- `S/R/T-DEF+20`

## 操作方法

### 添加能力

从左侧“特殊能力一览”中选择能力，然后添加至：

- 本体
- 素材1
- 素材2
- 素材3
- 素材4
- 素材5

也可以直接通过拖拽移动能力。

按住 `Ctrl` 拖拽时，可以复制能力，而不是移动能力。

### 垃圾能力

“垃圾”是用于开孔和占位的 100% 继承能力。

同一件装备中可以放置多个垃圾能力。

界面下方提供：

- 将本体和全部素材用垃圾能力补至 1S～8S
- 删除所有本体和素材中的垃圾能力

### 特殊能力因子

每件本体 / 素材上的部分能力可以设置为“因子”。

启用特殊能力因子后，该能力会按照特殊能力因子的规则进入追加候选。

### 使用追加道具

勾选“使用追加道具”后，追加候选中会显示追加道具能力。

追加道具能力基础成功率为 100%。

同一次特殊能力追加只能使用一个追加道具能力。

### 成功率补正

模拟器支持：

- 能力追加成功率道具
- 奖励期间
- 同名装备补正
- 扩槽补正
- 炼成之引导等能力补正

最终成功率会按照旧 PSO2 的规则进行计算。

## 已实现的部分特殊规则

### Phrase 系列

支持：

- フレイズ・チェイス
- フレイズ・レスポンス
- フレイズ・ウィーク
- フレイズ・リカバリー
- フレイズ・リデュース
- フレイズ・ディケイ
- フレイズレセプター

Phrase 系能力之间互斥，只能附加一个。

Phrase 系正常情况下不可普通继承，使用对应 Receptor 后可进行继承。

### Lesser / EV 系列

支持：

- レッサースタミナ I～V
- レッサースピリタ I～V
- レッサーパワー I～V
- レッサーシュート I～V
- レッサーテクニック I～V

以及：

- EV・パワーHP
- EV・パワーPP
- EV・シュートHP
- EV・シュートPP
- EV・テクニックHP
- EV・テクニックPP

EV 系按照对应 Lesser V 的组合进行特殊合成。

### 炼成之引导

当本体已经拥有“錬成の導き”时，本次特殊能力追加成功率 +5%。

仅将“錬成の導き”作为本次追加候选时，不会提前获得该 +5% 效果。

## 使用方法

本项目为纯前端离线网页。

下载后直接打开：

`index.html`

即可使用。

不需要安装 Node.js、Python 或其他运行环境。
